# Changelog

Все заметные изменения в проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

## [1.2.0] - 2023-10-15

### Добавлено

- Поддержка новых команд: `/weather` и `/news`.
- Интеграция с API погоды для предоставления актуальной информации.
- Локализация бота на английский и русский языки.

### Изменено

- Улучшена обработка ошибок при запросах к внешним API.
- Оптимизирована производительность бота.

### Исправлено

- Исправлена ошибка, из-за которой бот не отвечал на команду `/start`.
- Устранена утечка памяти при длительной работе бота.

## [1.1.0] - 2023-09-20

### Добавлено

- Команда `/help` для отображения списка доступных команд.
- Логирование ошибок в файл `bot.log`.

### Изменено

- Улучшено взаимодействие с пользователем: добавлены подсказки и клавиатура.

### Исправлено

- Исправлена ошибка, из-за которой бот не распознавал команды с опечатками.

## [1.0.0] - 2023-08-10

### Добавлено

- Первоначальный релиз бота.
- Базовая функциональность: команды `/start`, `/info`.
- Интеграция с базой данных для хранения пользовательских данных.
